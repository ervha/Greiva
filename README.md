# Greiva

書く、整理する、予定につなげる。

Greivaは、ノート・タスク・予定を一つの場所で扱うアプリを目指して開発しています。ブロック型のエディターを中心に、端末での保存を優先し、ネットワークの復帰後に同期する設計です。

## 目指す体験

- **ノート**: 見出し・リスト・Todo・Toggleなどのブロックで考えを整理する。
- **タスクと予定**: ノートと関連付け、曜日ごとの繰り返しや一回だけの取消・振替を扱う。時間割のほか、仕事や個人の予定にも使える。
- **AIによる作成・登録**: 文章や音声からノート・タスク・予定を作る。録音や音声ファイルからノートを整理し、抽出された候補を選んで登録する。
- **利用案内**: 操作中の文脈に合ったヘルプと、困ったときの解決手順へアクセスする。
