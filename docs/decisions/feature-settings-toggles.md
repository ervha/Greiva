# 機能・設定項目のトグル切り替え仕様の策定

2026-10-06 / v0.25.2。利用者の「設計項目、設定項目についてユーザーがON/OFFをトグルで切り替えることが可能にしたい。実際のコードは変更せず、仕様書のみ新規作成・追加・追記を行ってコミットまで行ってください」という指定に基づく仕様設計の追加。

- 設計項目（Task/Relationパネル、Calendar/時間割、汎用DBビュー、AI・音声アシスタント、ヘルプ案内）および設定項目（エディタ補完・ドラッグ・Markdown自動変換・IME保護ガード、ローカル完結モード、テレメトリ等）を、ユーザーが個別にON/OFFトグルで切り替え可能にする統合仕様書 `docs/plan/FEATURE_SETTINGS_TOGGLE_SPEC.md` を策定。
- 非破壊性の原則を明文化。モジュールをOFFに切り替えても、SQLiteやサーバー上の実データ（登録済みTask、予定、ノートなど）は決して削除されず、再有効化時に完全に復元される契約を規定。
- 設定のスコープを「端末ローカル設定（SQLite `local_settings` テーブル、即時反映）」と「ワークスペース設定（構造化同期）」に明確に分離。
- UI設計においてMaterial Design準拠のSwitchコンポーネント、A11y対応（`role="switch"`, `aria-checked`）、キーボード操作要件を定義。
- 実装コードの変更は含めず仕様書・計画文書の追加・更新のみであるため、バージョン運用規約に従いPATCH（v0.25.2）として記録。
